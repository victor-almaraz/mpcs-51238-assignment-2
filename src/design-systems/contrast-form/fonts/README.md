| Files | Family | Source | Licence |
|---|---|---|---|
| `OstrichSans-*.woff` | Ostrich Sans (Light, Medium, Black) by Tyler Finck | The League of Moveable Type, https://github.com/theleagueof/ostrich-sans (`webfonts/`), unmodified | SIL Open Font License 1.1 (`OstrichSans-OFL.md`) |
| `TeXGyreAdventor-Latin-*.woff2` | TeX Gyre Adventor (Regular, Bold) by GUST e-foundry | CTAN, https://ctan.org/pkg/tex-gyre (`texgyreadventor-regular.otf`, `texgyreadventor-bold.otf`) | GUST Font License (`TeXGyreAdventor-GUST-FONT-LICENSE.txt`) |

`TeXGyreAdventor-Latin-*.woff2` are modified versions of the TeX Gyre Adventor OpenType files: subset with `pyftsubset` to Basic Latin, Latin-1, general punctuation, arrows and a few symbols (U+0000–00FF, U+0131, U+0152–0153, U+02C6, U+02DA, U+02DC, U+2000–206F, U+20AC, U+2122, U+2190–2199, U+2212, U+2215, U+221E, U+2248), with all layout features kept, and converted to WOFF2. The original files are available from CTAN.
